# Patchbook for AI agents

If a user asked you to install Patchbook or its skills, follow [INSTALL.md](INSTALL.md). Install into the user's Claude account (Customize → Skills) or onto their own machine. Copying the skills into your session's workspace or container is not an install, because it is deleted when the session ends.

If you are working on this repository: change the review pages in `src/`, run `python3 src/build.py`, and commit `src/` together with the generated `skills/*/assets/review-template.html`.
